Privacy Policy — KBFC Live Update

Last updated: August 2026

This application ("KBFC Live Update") is an internal tool used by Kelab Bolasepak [Club Full Name] ("the Club", "we", "us") to publish live match updates to the Club's official Threads and Instagram accounts.

What We Access

This app connects only to Threads and Instagram accounts that are officially owned and managed by the Club. It does not access, collect, or store data from any other user's personal account. Access is limited to the minimum permissions required to publish content on the Club's behalf.

What We Publish

Match event updates — such as player names, event type (goal, substitution, card, etc.), and match minute — submitted by authorized Club administrators through our internal admin dashboard.

Data We Store

Access tokens used to authenticate with Threads and Instagram are stored securely on our servers and used solely to publish content on behalf of the Club's own social media accounts. We do not sell, share, or use this data for any purpose beyond operating this tool.

Data Retention & Deletion

Access tokens are retained only for as long as this tool remains in active use. To request removal of any data associated with this app, or to revoke access, contact us using the details below.

Third-Party Services

This app integrates with Meta's Threads API and Instagram Graph API to publish content. Use of these platforms is also governed by Meta's own privacy policies.
